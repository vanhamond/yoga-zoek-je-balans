# Yogaschool Zoek je Balans

Statische website voor GitHub Pages.

## Publiceren
1. Maak op GitHub een openbare repository met de naam `yoga-zoek-je-balans`.
2. Upload alle bestanden en de map `assets` uit dit pakket naar de hoofdmap van de repository.
3. Ga naar **Settings > Pages**.
4. Kies **Deploy from a branch**, branch **main**, map **/(root)** en klik **Save**.
5. De website verschijnt op `https://vanhamond.github.io/yoga-zoek-je-balans/`.

## Na publicatie
- Test de WhatsApp-, e-mail-, bel- en Google Maps-knoppen.
- Als de repository een andere naam krijgt, vervang dan de URL `https://vanhamond.github.io/yoga-zoek-je-balans/` in `index.html`, `robots.txt` en `sitemap.xml`.
- Voeg de website na publicatie toe aan Google Search Console en dien `sitemap.xml` in.
